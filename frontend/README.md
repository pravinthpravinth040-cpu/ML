# TrustCred AI — Frontend Web Application

A responsive, accessible, zero-build web interface for **TrustCred AI** cash-flow credit assessment and fraud detection. Built strictly with plain HTML5, Vanilla CSS, and Vanilla JavaScript (with Chart.js via CDN).

---

## 1. Quick Start & Execution

The application is completely self-contained and runs in any modern browser without npm, Node.js, or build steps.

### Method A: Direct Double-Click (`file://`)
Simply double-click `frontend/index.html` in your file explorer.
> **Note**: An embedded fallback (`js/data.js`) automatically serves the 40-vendor dataset and scorecard outputs without being blocked by browser local file CORS policies.

### Method B: Local Python HTTP Server
Run the standard Python web server from the repository root:
```bash
python -m http.server 8000
```
Then navigate to:
- **Underwriter / Lender Dashboard**: [http://localhost:8000/frontend/](http://localhost:8000/frontend/) (or `frontend/index.html`)
- **Vendor Mobile Experience (Bilingual EN/TA)**: [http://localhost:8000/frontend/vendor.html](http://localhost:8000/frontend/vendor.html) (or `frontend/vendor.html`)

## 2. Plugging in ML Model Outputs (`vendor_scores.csv`)

The frontend dynamically searches for `data/vendor_scores.csv` (generated by `python ml-training/train.py`):
1. **When `vendor_scores.csv` is present:**
   - The application parses the CSV directly into memory.
   - It populates the exact model predictions: `final_score`, `score_band`, `underwriting_decision`, `fraud_flag`, factor points, and plain-language underwriting explanations.
   - The status badge in the top navigation displays: `ML Scorecard Active (vendor_scores.csv)`.

2. **When `vendor_scores.csv` is absent (or standalone mode):**
   - The frontend automatically executes `js/score.js` (transparent 100-point client-side scoring logic).
   - Labels the output with a `demo` tag, ensuring the application remains 100% operational in any environment.

## 3. Key Pages & Components

1. **Sticky Top Navigation & Theme Toggle:**
   - Smooth navigation anchors across sections.
   - Light and Dark mode toggle respecting system preferences (`prefers-color-scheme`) and saving choices to `localStorage`.
2. **Hero & Portfolio Summary Cards:**
   - Portfolio aggregates: Total Vendors (40), Total Loan Requested (₹2,090,000), Flagged Accounts (9 circular-flow candidates), and Average Score.
3. **Interactive Search & Filter Toolbar:**
   - Real-time search by Vendor ID (`V001`-`V040`) or loan amount.
   - Multi-factor filtering by Score Band (`Strong`, `Moderate`, `Limited`, `Insufficient`) and Genuineness Status (`Genuine`, `Flagged`).
   - Live sorting by score, 90-day receipts, requested loan, and net cash flow.
   - Live count announcement (`aria-live="polite"`) for accessibility.
4. **Vendor Directory (Table / Mobile Touch Cards):**
   - Desktop view: Accessible HTML table with color-coded badges and circular flow warning pills.
   - Mobile view (< 700px): Switches to touch cards with minimum 44px hit targets.
5. **Vendor Detail Drawer (Slide-Over Modal):**
   - Accessible keyboard control (Esc key closes, focus restoration).
   - Animated SVG score gauge.
   - **Prominent Red Warning Box** for circular transfer vendors: *"Money moved back and forth between vendors; turnover may be inflated."*
   - Plain-language underwriting summary.
   - 5 Factor Bars with (?) tooltip popups for factor rationale.
   - Financial velocity grid (receipts, expenses, net flow, unique customers, EMI, coverage buffer).
   - Interactive Chart.js charts: Monthly receipts trend & loan vs net cash flow comparison.
   - **Download / Print Report** button invoking `window.print()` with a printer-optimized stylesheet.
6. **Loan Simulator:**
   - Interactive sliders for Loan Principal (₹10,000 to ₹100,000) and Tenure (6 to 24 months).
   - Dynamic EMI calculation at flat 20% p.a. illustrative interest.
   - Real-time debt coverage ratio against the vendor's empirical monthly net cash flow with semantic Green/Amber/Red status indicator.
7. **Side-by-Side Comparison:**
   - Compare up to 3 vendors simultaneously across all scorecard pillars and cash-flow health metrics.
8. **Methodology & Limitations Explainer:**
   - Explains the 4-step UPI evidence underwriting framework.
   - Explicit disclaimer stating that this is an empirical cash-flow evidence score, not a credit bureau rating, and does not predict future default.

---

## 4. Key Design Decisions

- **Vanilla Stack with Zero Dependencies:** No build systems, no npm vulnerabilities, zero runtime friction. Opens immediately in any browser.
- **Dual Data Layer:** Combines `fetch()` with an embedded fallback (`js/data.js`) to guarantee flawless offline and `file://` execution.
- **Semantic Spacing & Typography:** Built on an 8px modular scale using Google Fonts `Inter` with system font fallbacks.
- **Accessibility First:** High-contrast text (>= 4.5:1), visible focus rings (`:focus-visible`), never relying on color alone for status indication (accompanying text & icons), and `prefers-reduced-motion` compliance.

---

## 5. Known Limitations

- **Small Dataset (40 Vendors):** Designed around the synthetic 40-vendor demonstration dataset.
- **Empirical Velocity Only:** As documented in the underwriting disclaimers, the score reflects bank account transaction velocity and counter-party legitimacy; it does not model consumer credit willingness or historical default.
